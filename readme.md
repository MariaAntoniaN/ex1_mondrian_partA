# Exercicio 1 - Mondrian - Parte A

Para o desenvolvimento deste trabalho, utilizei previamente o Adobe Illustrator para definir as coordenadas e os tamanhos das linhas e dos retângulos, replicando, com as ferramentas vetoriais, as formas no programa. Como também usei o conta-gotas para alcançar, com rigor, a cor exata de cada elemento. 
Para fazer as linhas e os retângulos e as restantes funções, usei o line() e o rect() respectivamente, recorrendo ao site do p5.js.
Para dar um ar mais realista ao meu quadro, quis dar detalhes que fizessem parecer uma tela; para tal, repliquei a assinatura do artista com text() e, no seu fundo, criei um degradê com o “for”, porque, se olharmos bem para a imagem, o fundo não é 100% branco, na parte inferior da tela, o branco tem uma tonalidade mais avermelhada.
